# AI Essay Tutor

Grades PSLE-level English and Simplified Chinese composition essays. Photograph
the question and the handwritten essay; the app transcribes it, scores it
against the PSLE rubric, and shows redline corrections, comments, and an
improved version — like a teacher marking the page.

It runs as an **installable PWA served from your own AI server** (an Ubuntu box
running [Ollama](https://ollama.com) with `gemma4:26b`), reached over
[Tailscale](https://tailscale.com). Nothing leaves your private network — the
right answer for children's handwritten essays.

**Status:** in development. See `docs/web-solution-plan.md` for the full design.

## Architecture

```
Any device on the tailnet (phone / tablet / desktop)
   │  installs the PWA, opens https://aiserver.<tailnet>.ts.net  (TLS via `tailscale serve`)
   ▼
FastAPI app (127.0.0.1:8765 on the AI server) ── serves the PWA + session API
   │  OpenAI-compatible /v1 (localhost)
   ▼
Ollama → gemma4:26b   (OCR + picture description + rubric grading)
```

- **Sessions persist server-side.** Uploads, transcription, and the grade live
  in SQLite + per-session image folders on the server. Shoot the pages on a
  phone, then open the marked result on a desktop — the "Recent" list and the
  per-session link (`#s/<id>`) make the hand-off seamless.
- **Transcription and grading run as background jobs** on a single worker, so a
  slow 26B grade outlives the browser tab and only one essay is processed at a
  time.
- **PWA.** Installable, with an offline app shell. The service worker never
  caches `/api/*` (inference is always server-side).

> **Privacy:** essays are processed entirely on your own AI server and never
> leave your tailnet. There is no cloud provider and no API key.

## Layout

- `server/` — FastAPI app. Serves the PWA (`aitutor_server/static/`); the Ollama
  client + transcriber/grader live in `aitutor_server/providers/`; persisted
  sessions + the job runner in `aitutor_server/sessions.py`.
- `scripts/` — `make_icons.py` (PWA icon generator) + PowerShell dev helpers.
- `android/` — **parked.** The on-device Android build, kept in git history; not
  part of the current build (the PWA over Tailscale replaces it).
- `extension/` — **parked.** The original LibreOffice `.oxt` front-end.

Deployment (systemd service + `tailscale serve` TLS) lives in the
`ubuntuserver` repo's `provision-essay-tutor.sh`.

## Run locally (dev)

```bash
cd server
python -m pip install -e '.[dev]'
# point at your Ollama (defaults to localhost:11434 if it's on this box)
export AITUTOR_OLLAMA_URL=http://aiserver:11434/v1
python -m aitutor_server.main --host 127.0.0.1 --port 8765 --open
```

Config via environment (or `.env` — see `.env.example`):

| Var | Default | Purpose |
|---|---|---|
| `AITUTOR_OLLAMA_URL` | `http://127.0.0.1:11434/v1` | OpenAI-compatible Ollama base URL |
| `AITUTOR_MODEL` | `gemma4:26b` | model tag |
| `AITUTOR_DATA_DIR` | `~/.local/share/AIEssayTutor` | sessions DB + image storage |

## Front-end

A no-build vanilla-JS PWA in `server/aitutor_server/static/` (served by the same
FastAPI process). The span-anchoring engine that renders redlines and comments
(`js/annotate.js`) is the browser replacement for the old `writer_ops.py`. Icons
are generated by `scripts/make_icons.py` (stdlib only).

## Tests

```bash
cd server && python -m pytest          # grader validation (offline)
node --test tests/js/annotate.test.mjs # front-end span-anchoring engine
```
